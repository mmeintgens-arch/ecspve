    Eigenes Passwort festlegen

    Du hast ein Startpasswort bekommen. Bitte ersetze es jetzt durch ein eigenes – mindestens 12 Zeichen, am besten aus dem Passwort-Manager.

    Handy nicht zur Hand? Hier geht auch einer eurer Notfallcodes (xxxxx-xxxxx) – jeder nur einmal.

    Zweiten Faktor einrichten

    Zur Sicherheit braucht die Anmeldung neben dem Passwort einen Code vom Handy. Einmalig einrichten:

    1. Eine Authenticator-App öffnen – z. B. Microsoft Authenticator, Google Authenticator, Aegis oder 2FAS.
    2. Den QR-Code scannen – jeder Benutzer hat seinen eigenen.
    3. Den 6-stelligen Code aus der App unten eintragen.

    Kein Scannen möglich? Schlüssel von Hand eingeben: · auf diesem Handy direkt in der App öffnen

    Eure Notfallcodes

    Falls das Handy verloren geht: Mit jedem dieser Codes kommt ihr einmal ohne App hinein. Jetzt ausdrucken oder im Passwort-Manager speichern – sie werden nicht noch einmal angezeigt.
