🖥️ ECS Proxmox – Übersicht der Container und Dienste

Python-Dienst ecspve auf Port 8080 – nur HTTP, HTTPS macht euer Caddy davor (reverse_proxy <IP>:8080). Was den Host betrifft, erledigt /usr/local/sbin/ecspve-helfer auf dem Proxmox-Host – der Container ruft ihn per SSH mit einem Schlüssel auf, der nur diesen Helfer starten darf.

WasWo
Programm/opt/ecspve (wird bei jedem Update ersetzt)
Einstellungen/etc/ecspve/ecspve.env – Port, Token, Snapshots, Benachrichtigungen
Auswahl „nachts automatisch“, letzter Nachtlauf/var/lib/ecspve
SSH-Schlüssel zum Helfer/etc/ecspve/ssh
Helfer, Aufträge und Protokolleauf dem Proxmox-Host: /usr/local/sbin/ecspve-helfer, /var/lib/ecspve-helfer/auftraege, /etc/ecspve/helfer.conf
Projektordnerauf dem Host: /opt/ecspve
Passwortauf dem Host: /root/ecspve-ctCTID-passwort.txt

Vom Proxmox-Host (Container CTID)

/opt/ecspve/pve-install.sh --pull             # Update: neuesten Stand holen, Container und Helfer erneuern
ecspve-helfer uebersicht | head -c 400        # Helfer von Hand testen
journalctl -u 'ecspve-*' -n 50                # Protokoll der Aufträge (Updates, Neustarts)
pct enter CTID                                # Konsole im Container

Im Container

ecspve status                   # Übersicht im Terminal
ecspve verbindung               # erreicht der Container den Helfer?
ecspve passwort                 # Passwort der Weboberfläche neu setzen
ecspve token --neu              # neues Token für Monitoring-Abfragen
systemctl list-timers ecspve-nacht.timer   # nächster Nachtlauf
journalctl -u ecspve -f         # Protokoll live (Strg+C beendet)
